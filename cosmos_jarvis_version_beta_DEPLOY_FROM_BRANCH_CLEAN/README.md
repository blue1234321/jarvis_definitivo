# COSMOS JARVIS — Deploy from a branch

Paquete limpio para GitHub Pages usando **Deploy from a branch**.

## Estructura
- `index.html` — página central COSMOS JARVIS
- `standard.html` — página STANDARD (en desarrollo)
- `premium.html` — página PREMIUM
- `COSMOS DEFINITIVO - STANDARD.html` — descarga de STANDARD
- `COSMOS DEFINITIVO - PREMIUM.html` — descarga de PREMIUM

## GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch** → `main` → `/ (root)`.

No requiere GitHub Actions.
