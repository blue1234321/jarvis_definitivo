# COSMOS JARVIS · Deploy from a branch

Paquete limpio para GitHub Pages usando **Deploy from a branch**.

## Estructura
- `index.html` — página central
- `standard.html` — única página STANDARD (en desarrollo)
- `premium.html` — única página PREMIUM
- `premium-access.html` — acceso Premium con `pikari`

No usa GitHub Actions y no contiene carpetas anidadas ni copias de `COSMOS DEFINITIVO`.

## GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)`.
